# Frozen study plan · 19 November 2026

Question: in a known six-record feature import block whose row keys were lost, which vertex's original feature slot should an operator verify when exactly one truthful lookup is affordable? Return a bijection for the whole block. The clean alignment is known to the benchmark evaluator. Faults are injected. We assume trusted outer records and known block membership, with no trusted copy of a suspect vertex's own vector. If durable join keys or per-record hashes are available, use those directly.

Use the three existing public-data derivatives Cora, ogbn-arxiv-20k, and OpenAlex-20k. Seed 191126. Split vertices into 55% anchor, 15% calibration, remainder evaluation, with column slots independently and uniformly shuffled. Build graph neighborhoods exclusively from anchor features. Retain isolates. Fit direct centered cosine or ridge neighborhood predictors on anchors; choose the score model and positive temperature by calibration block log loss. Never use test labels to choose them. Normalize features and center on anchors. Reuse the historical files only for public features and edges, never query traces or old results.

Primary regime: random disjoint blocks in the test fold. Secondary: stratify by the projection of the anchor-neighbor context onto a fixed random direction, shuffle within bands of 30, then take disjoint groups of six. A second seed (201126) separately repeats the whole construction and split. Never pool repetitions as independent graphs or blocks. A shuffled-context control breaks the row-context correspondence inside each block without changing its columns. All queries share the chosen score matrix and temperature.

Compare no lookup, a uniformly random row (exact mean over six possible actions), lowest top-two rowwise gap, highest posterior marginal entropy with the exact permutation law, and the proposed whole-block expected-success policy. All one-lookup policies use the same constrained assignment decoder. Primary outcome is exact recovery of the source serialization for all six rows. Also measure fraction of rows recovered, policy agreement, performance on the negative control, and attainable best single lookup. Report paired intervals across disjoint blocks within each graph and seed, conditional on this graph/split; distinguish these from replicated independent datasets. A retained empirical direction should improve complete-block accuracy by at least five percentage points over a random lookup on at least two primary datasets in both seeds; claim superiority over entropy only when supported separately. Report all tested datasets/conditions and any regressions. If exact active selection ties entropy, its computational and task implications can still be studied, conditional on the gate above. Distinguish model optimality from experimental performance.

Independent validation on the supplied server: compare the all-pairs exchange-cost algorithm with exhaustive enumeration and forced linear assignments, including ties and negative entries. Measure score-to-all-action-values timing against competent exact references across block sizes; exclude disk I/O and predictor training from the kernel timing. No network lookup latency is simulated or counted. No broad novelty or production-repair claim follows from an injected fault.
