# External domain replication

Before viewing the primary study outcomes we added Amazon Computers as an independent non-bibliographic domain because the three planned datasets all describe scholarly records. Reuse the frozen split, two seeds, six-row blocks, feature model and calibration grid, both group formation regimes, shuffled-context controls, and all policies from study.py and secondary.py. No changes to primary retention criteria. Original sparse arrays and source revision are recorded under public_data/. Use the public attribute and adjacency matrices as distributed, without label input. Results are separately identified as the transfer experiment. The scorer is calibrated anew on each dataset, so this tests transfer of the protocol, not zero-shot model weights.
